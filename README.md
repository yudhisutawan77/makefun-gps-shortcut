## What it does

`main.py` writes a single line — at most 200 characters — the GPS's own
excuse for sending the driver down the wrong road, to
`/output/entry.txt`.

> My 2019 map still calls this lake a shortcut, and I trust it, because
> that map has never once apologized to me.

The GPS is smug, defensive, and blames the map: the lake is a shortcut
on a 2019 map, and the punchline is that the map has never once
apologized — so why would the GPS start doubting it now?

## Run

```sh
python3 main.py
# writes /output/entry.txt (or $ENTRY_OUT/entry.txt when ENTRY_OUT is set)
```
